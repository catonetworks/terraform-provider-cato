# cato_role (Resource)

Manages an account-local custom IAM role. Updates replace the complete permission set. Predefined roles are immutable and must be read through data sources.

## Example Usage

```terraform
# Example usage:
#   export TF_VAR_token="your-api-token"
#   export TF_VAR_account_id="123456"
#   terraform init
#   terraform plan

terraform {
  required_providers {
    cato = {
      source = "catonetworks/cato"
    }
  }
}

variable "token" {
  description = "Cato API token (set with TF_VAR_token)."
  type        = string
  sensitive   = true
}

variable "account_id" {
  description = "Cato account ID (set with TF_VAR_account_id)."
  type        = string
}

variable "baseurl" {
  description = "Cato GraphQL API endpoint."
  type        = string
  default     = "https://api.catonetworks.com/api/v1/graphql2"
}

provider "cato" {
  baseurl    = var.baseurl
  token      = var.token
  account_id = var.account_id
  #retry_max              = 3
  #retry_wait_min_seconds = 10
  #retry_wait_max_seconds = 30
}

resource "cato_role" "example" {
  name = "tf-doc-example-role"
  # account_id  = var.account_id
  # description = "Read-only site access"
  permissions = [
    { resource = "Sites", action = "VIEW" },
  ]
}

output "role_id" {
  value = cato_role.example.role_id
}

# Import a custom role using ACCOUNT_ID:ROLE_ID:
# terraform import cato_role.example 123456:98765
```

## Schema

### Required

- `name` (String) Custom role name.
- `permissions` (Attributes Set) Complete set of permissions. Each resource may appear once. Use an explicit empty set to grant no permissions. (see [below for nested schema](#nestedatt--permissions))

### Optional

- `account_id` (String) Account owning the role. Defaults to the provider account_id; changing it replaces the resource.
- `description` (String) Role description. Omit or set to an empty string to clear it.

### Read-Only

- `account_type` (String) Account type applicable to this role.
- `id` (String) Resource identifier in ACCOUNT_ID:ROLE_ID format.
- `is_used_on_external_access` (Boolean) Whether external access currently uses the role.
- `predefined` (Boolean) Whether the role is predefined. Managed custom roles are always false.
- `role_id` (String) Stable API role identifier.

### Nested Schema for `permissions`

Required:

- `action` (String) Granted action: VIEW or EDIT.
- `resource` (String) Resource identifier from cato_permission_catalog, for example Sites.

## Import

Import an existing **custom** role using `ACCOUNT_ID:ROLE_ID`. Predefined roles cannot be managed by this resource; use the `cato_role` data source to read them.

```shell
# Import an existing custom role using its account and role identifiers.
terraform import cato_role.example 123456:98765
```
